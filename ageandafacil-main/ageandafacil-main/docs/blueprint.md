# **App Name**: SchoolLens Scheduler

## Core Features:

- User Authentication & Role Management: Secure login for administrators and teachers with distinct access permissions to manage their respective functionalities.
- School Structure & Location Setup (Admin): Administrators can register school segments (e.g., Educação Infantil), classes (e.g., Maternal), and photo locations (e.g., Pátio, Biblioteca) to reflect the school's organizational structure.
- Scheduling Configuration (Admin): Administrators define available time slots per segment/class, set the default session duration (e.g., 60 minutes), and block specific dates or times to prevent bookings.
- Intelligent Appointment Scheduling (Teacher): Teachers can view truly available time slots and book photo sessions for their classes. The system intelligently prevents time overlaps by blocking any partially coinciding slots when a reservation is made.
- Visual Appointment Calendar: A dynamic calendar interface displaying available slots, booked sessions for a quick visual overview. Teachers see their own, while admins see all school-wide bookings.
- Appointment Management & Oversight: Teachers can view, edit, or cancel their scheduled appointments. Administrators have a comprehensive list of all bookings with options to filter, view details, and manage them.
- AI Session Brief Assistant: An AI tool to assist teachers in generating detailed and helpful 'Observations' for their photo session bookings, ensuring all relevant information for the marketing team (e.g., specific activities, preferred shots) is easily captured.

## Style Guidelines:

- Light color scheme for clarity and professionalism suitable for an educational environment.
- Primary action color: A professional and trustworthy Royal Blue (#2258CC), symbolizing reliability and organization. It's vibrant enough for calls to action without being overly aggressive.
- Background color: A very light, desaturated blue (#ECF1FA) derived from the primary hue, providing a clean and subtle base that enhances readability without distraction.
- Accent color: A fresh Aqua/Cyan (#56CEDE), chosen as an analogous color to the primary, to highlight key information or interactive elements, offering clear contrast and visual interest.
- Primary font: 'Inter' (sans-serif) for all text elements. Its modern, objective, and neutral aesthetic ensures high readability and a clean, efficient appearance suitable for forms and calendar views.
